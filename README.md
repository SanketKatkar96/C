# C
1️⃣ What Is C Programming?
C isn’t just a language. It’s the bedrock of software development — fast, lean, and beautifully logical.

Developed by Bjarne Stroustrup’s mentor, Dennis Ritchie, C was built to do one thing really well: control the machine without unnecessary baggage..

It’s procedural. That means we write step-by-step instructions — like telling a robot exactly how to tie its shoes.



C is a Programming Language

C is a general-purpose programming language.

It is used to develop system software, applications, operating systems, etc

Developed by

C was developed by Dennis Ritchie at Bell Labs around 1972.

Procedural Language

C follows a procedural programming approach.

Program is divided into functions.

Case Sensitive

C is case-sensitive.

Name, name, and NAME are different.

Compiler Based
C programs are converted into machine code using a compiler before execution.
