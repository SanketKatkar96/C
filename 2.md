Operators in C
Operators are symbols used to perform operations on values.
Operator	Purpose	     Example
-    +       	Addition    	  a + b
-    -       	Subtraction	    a - b
-    *	     Multiplication	  a * b
-    /        	Division	    a / b
-    %	        Remainder	    a % b
-    ==	      Equal to	      a == b
-    >	      Greater than	  a > b
-    &&	     Logical AND	    a > 0 && b > 0
